# Databases and DBMS

A database management system stores, retrieves and manages data.

## Relational Databases
Relational databases organize data into tables with rows and columns. SQL is used to define and query relational data.

## Primary Key
A primary key uniquely identifies a row in a table.

## Foreign Key
A foreign key references a key in another table and helps enforce relationships.

## Normalization
Normalization organizes relational data to reduce unnecessary duplication and update anomalies.

## SQL
SQL supports data definition, querying, insertion, updates and deletion. Common clauses include SELECT, FROM, WHERE, GROUP BY, HAVING and ORDER BY.

## MongoDB
MongoDB is a document-oriented database that stores JSON-like documents. It is commonly used when flexible document structures are useful.
