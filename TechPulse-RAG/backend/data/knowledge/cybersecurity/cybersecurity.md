# Cybersecurity Fundamentals

Cybersecurity protects systems, applications, networks and data from unauthorized access and misuse.

## CIA Triad
Confidentiality limits information access, integrity protects correctness, and availability keeps systems usable.

## Authentication and Authorization
Authentication establishes identity; authorization controls permissions.

## Encryption
Encryption transforms readable data into ciphertext using a cryptographic algorithm and key.

## HTTPS
HTTPS uses TLS to protect HTTP traffic in transit.

## Common Risks
Common application security risks include injection, broken access control, insecure authentication, sensitive-data exposure and misconfiguration.
