# Cloud and DevOps

Cloud computing provides computing resources such as servers, storage and databases through managed infrastructure.

## Containers
Containers package an application and its dependencies into an isolated runtime environment. Docker is widely used for containerization.

## CI/CD
Continuous Integration automates building and testing changes. Continuous Delivery or Deployment automates delivery of software to environments.

## Git
Git is a distributed version-control system. Common commands include clone, add, commit, branch, merge, pull and push.

## Deployment
Applications can be deployed to virtual machines, containers, platform-as-a-service environments or serverless platforms.
