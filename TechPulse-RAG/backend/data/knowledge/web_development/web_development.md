# Web Development

Web applications commonly have a frontend, backend and data layer.

## HTML
HTML structures web pages using elements such as headings, paragraphs, links, forms and sections.

## CSS
CSS controls presentation, layout, spacing, typography and responsive behavior.

## JavaScript
JavaScript provides client-side behavior and can call backend APIs using fetch.

## REST APIs
A REST-style API exposes resources through HTTP methods such as GET, POST, PUT, PATCH and DELETE. JSON is commonly used for request and response bodies.

## React
React is a JavaScript library for building component-based user interfaces.

## Node.js
Node.js is a JavaScript runtime commonly used for backend services and tooling.

## Express
Express is a Node.js web framework commonly used to build HTTP APIs.

## FastAPI
FastAPI is a Python framework for building APIs with type hints, request validation and automatic OpenAPI documentation.
