# Computer Science Fundamentals

## Operating Systems
An operating system manages hardware resources and provides services for applications.

## Processes
A process is a running program with its own execution context and resources.

## Threads
A thread is an execution path within a process. Multiple threads can share process resources.

## Computer Networks
Networks allow devices to exchange data using protocols.

## TCP and UDP
TCP provides connection-oriented, reliable, ordered delivery. UDP is connectionless and does not provide the same delivery guarantees.

## HTTP
HTTP is an application-layer protocol used for communication between clients and servers. HTTPS adds TLS protection.
