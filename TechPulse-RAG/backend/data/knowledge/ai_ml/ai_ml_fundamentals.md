# AI and Machine Learning Fundamentals

Artificial intelligence is a broad field concerned with systems that perform tasks associated with human intelligence.

## Machine Learning
Machine learning learns patterns from data instead of relying entirely on explicitly written rules.

## Supervised Learning
Supervised learning uses labeled examples. Classification predicts discrete labels; regression predicts continuous values.

## Unsupervised Learning
Unsupervised learning finds structure in unlabeled data. Clustering and dimensionality reduction are common examples.

## Neural Networks
Neural networks use layers of parameterized transformations. Training adjusts parameters to reduce a loss function.

## Deep Learning
Deep learning uses neural networks with multiple layers and is widely used for language, vision, speech and multimodal tasks.

## LLMs
Large language models are neural models trained on large text corpora to model language. Modern LLM applications commonly use prompting, retrieval, tool use and structured outputs.
